Google Sheet sync — not connected

Stored on this device only, never sent anywhere except your own sheet. Paste the same URL and secret on every device you use.

First time? Create the sheet about 10 minutes
  1. Open sheets.new. Name it anything. Leave it empty — the tabs create themselves.
  2. In that sheet: Extensions ▸ Apps Script. Delete the myFunction stub already in the editor.
  3. Press Generate for a secret, then Copy script below and paste it into the editor. Save.

    The copied script already contains your secret — no editing needed.

  4. Deploy ▸ New deployment. Gear icon ▸ Web app. Set Execute as: Me and Who has access: Anyone, then Deploy.
  5. Google warns “Google hasn’t verified this app” — expected, you wrote it. Advanced ▸ Go to … (unsafe) ▸ Allow.
  6. Copy the Web app URL (ends in /exec) into the box above and press Save & sync.

Other devices: steps 1–5 are done once. Don't retype anything — press Copy device link above and open that link on the other device. It configures itself and syncs. The link carries the secret, so send it the way you'd send a password, and delete the message afterwards.

Setting someone else up with their own log? Send them a copy of your sheet with the script already inside: take your spreadsheet's address and replace the trailing /edit with /copy. One click gives them their own sheet and script, so they skip steps 1–3 and only deploy. They must generate their own secret and redeploy — a copied deployment is not theirs.

Anyone holding both the URL and the secret can read and edit this data, so treat the pair as a password. The script can reach nothing else in your Google account. If you edit the script later, redeploy it — Deploy ▸ Manage deployments ▸ pencil ▸ Version: New version. Saving alone changes nothing, which catches everyone once.
